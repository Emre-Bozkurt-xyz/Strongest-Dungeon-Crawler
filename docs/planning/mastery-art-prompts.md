# Mastery Art Prompts

Image-generator prompts for the mastery mind-space (`mastery-mind-space.md`): mastery emblems, node
icons, embroidery frames and the attunement token. Plain passives need no art; they are bare
circles drawn in code.

## How to use

1. Paste the **style block** once at the start of a chat, then one **subject** per image. If the
   generator drifts, paste the style block again.
2. Ask for **1024 × 1024 PNG with a transparent background**. If the generator cannot do
   transparency, ask for pure white on solid black and remove the background afterwards.
3. Save each file under the name given, upload it to Roblox, and send me the asset ids, by name.
   The code tints the white artwork (grey when inactive, white when active), so the art must be one
   colour.
4. Do a few first (the six emblems and two or three forms) so we can judge the style before
   generating the rest.

## Style block

> Minimalist ornamental emblem for a dark fantasy game interface. Pure white line art on a fully
> transparent background — one colour only: no grey, no shading, no gradients, no glow, no colour.
> Thin, elegant, even strokes with fine engraved or embroidered detail, like silver thread or an
> etching. A single centred symbol, readable at small sizes, fitting inside a circle with generous
> padding. Dreamlike and celestial: a symbol from inside a warrior's mind. No text, no letters, no
> background, no outer border.
